
# Steps to run the project in local

### Software dependencies:    
User must have Python3 installed in their system

1. Clone the repository
2. Open the project in Visual Studio PyCharm or any other IDE
3. Download important libraries by running the following command in terminal
    ```bash
    pip install -r src/src/requirements.txt
    ```
4. navigate to src folder
    ```bash
    cd src/
    ``` 
5. Open terminal and run the following command one by one
  ```bash
  streamlit run src/webwork.py
    ```
6. Browser will Automatically open or open the browser and go to the following link
   ```bash
    http://localhost:8501/
    ```
